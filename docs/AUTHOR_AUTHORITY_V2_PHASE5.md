# Author Profile V2 — Phase 5A: read-only experimental projection

The first slice adds an explicit, nonpersistent preview via `?authorityPreview=1` in the corpus entry URL. Default behavior remains unchanged. No production merge or rollout is authorized. The revision is pinned to the existing Hugging Face dataset; no direct OpenAlex API requests are added.

The preview reads contribution decisions from the completed discovery shadow, not inferred personal identities. It groups exact DOI or provider/source IDs, never titles; conflicting positive and rejected decisions remain ambiguous. Counts describe document groups, not total philosophical output. Other creators' unresolved mentions do not automatically negate a supported attribution. Missing source creators and shadow capture diagnostics remain visible. The preview has five states, title search, pagination, expandable source evidence, roles and DOI links. Evidence uses DOM text, not injected HTML. It does not change original results, saved items, ORCID, SIVA, Atlas, timelines, or legacy statistics.

The layout uses existing corpus/profile theme tokens. Browser smoke covers geometry at 320/390/768/1024/1440 and controls; broader all-theme checks and production integration remain pending. The existing full archive remains available and explicitly identified as legacy in the experimental panel. This is not the final Author Profile V2; later work must unify per-work decisions with identity decisions, handle verified contradictory evidence at creator level, preserve stable IDs, add canonical-card navigation for shadow-only records, and only then replace legacy statistics after validation. Phase 4 mobile verification and phase 5 CI must pass before closing either gate.
