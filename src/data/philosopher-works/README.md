# Philosopher Works Matrix

Matriz bibliográfica normalizada por autor para los 1,504 filósofos/pensadores del inventario canónico.

## Principios

- Un archivo JSON por autor.
- Separar obra original de edición/testimonio.
- No inventar año de publicación para obras orales, manuscritas o prehispánicas.
- Registrar coautoría y otros roles por separado.
- Toda palabra clave lleva procedencia: editorial, catalog, scholarly o inferred.
- Los conflictos de autoridad se conservan visibles hasta resolverlos.
- Cada ficha indica su cobertura.

## Estructura

- _schema.json
- manifest.json
- authors/0001.json ... authors/1504.json

## Lote 001

Autores 0001–0010. Este lote es un seed verificado de obras principales; no declara exhaustividad final.
