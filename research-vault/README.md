# Research Vault

Este directorio es la memoria conceptual y metodológica versionada de **Investigación Filosófica**.

Está diseñado para abrirse directamente como un *vault* de Obsidian, pero todos sus contenidos son Markdown estándar y deben seguir siendo útiles sin Obsidian.

## Cómo abrirlo en Obsidian

1. Instale Obsidian.
2. Elija **Open folder as vault**.
3. Seleccione la carpeta `research-vault` del repositorio.
4. Comience por [[00_HOME]].

## Reglas

- El runtime de la aplicación no depende de Obsidian.
- No se versiona `.obsidian/`.
- No se guardan credenciales, tokens ni secretos.
- Las decisiones importantes deben tener un ADR en `12-Decisions/`.
- Cada fase relevante debe actualizar [[01_PROJECT_STATE]] y dejar un log.
- La información interpretativa generada por IA debe distinguirse de datos bibliográficos y evidencia textual.
