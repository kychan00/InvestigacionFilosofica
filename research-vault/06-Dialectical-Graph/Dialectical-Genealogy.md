# Dialectical Genealogy

## Objetivo

Reconstruir cómo una dificultad filosófica se transforma a través de posiciones, críticas, respuestas y reformulaciones históricas.

## No hacer

No clasificar mecánicamente:

```text
tesis
antítesis
síntesis
```

## Sí hacer

Modelar relaciones concretas:

- formula;
- presupone;
- acepta;
- rechaza;
- objeta;
- refuta;
- concede;
- distingue;
- matiza;
- responde;
- reformula;
- radicaliza;
- integra;
- transforma;
- abandona;
- hereda;
- abre un nuevo problema.

## Forma mínima

```text
Problem P1
   ↓ formulated by
Position A
   ↓ opens
Problem P2
   ├─ answered by B
   ├─ objected to by C
   └─ reframed by D
            ↓
         Problem P3
```

## Dimensión temporal

El orden cronológico es necesario pero no suficiente.

Deben distinguirse, cuando sea relevante:

- fecha original de la obra;
- edición;
- traducción;
- publicación del comentario;
- fecha del debate secundario.

## Evidencia

Una arista del grafo no es un hecho por existir en el modelo.

Debe registrar:

- quién establece la relación;
- evidencia;
- tipo de evidencia;
- confianza;
- si la relación proviene del texto o de inferencia del sistema.

## Resultado

La genealogía debe permitir preguntar:

- ¿de dónde viene este problema?
- ¿qué posición introdujo esta distinción?
- ¿qué objeción provocó esta reformulación?
- ¿qué elementos se conservaron?
- ¿qué quedó abierto?
